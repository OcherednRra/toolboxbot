# Toolbox Bot

Телеграм-бот, который присылает пачками ассеты из Roblox Creator Store.
Под каждой карточкой кнопка 🔖 — ассет улетает в **Saved** твоего аккаунта
Roblox и сразу виден в Studio → Toolbox → Saved.

```
/next    следующий ассет, сначала самое свежее
/stats   очередь и статистика
/cats    какие типы ассетов собирать
/fresh   фильтр по возрасту ассета
/saved   последние сохранённые
```

Кнопка **⏭ Дальше** удаляет карточку из чата и сразу присылает следующую —
листать можно, не отрывая пальца от одной кнопки. Если сообщение старше
48 часов (столько телеграм даёт боту на удаление своих сообщений), карточка
остаётся, но кнопки у неё гаснут.

В карточке: превью, название, автор, рейтинг процентом с разбивкой на
голоса, цена, дата, описание и техсводка — сколько внутри скриптов,
полигонов, мешей, аудио и текстур. Скрипты вынесены вперёд не просто так:
бесплатная модель со скриптами — классический способ занести в игру чужой
код, и по числу сразу видно, стоит ли лезть внутрь.

Под каждой карточкой кнопка **🧠 Разбор** — Claude объясняет, что это за
ассет на самом деле, открывает найденные в описании ссылки на девфорум и
roblox.com, оценивает, сходится ли число скриптов с назначением вещи, и
выносит вердикт. Кнопка появляется, только если задан `ANTHROPIC_API_KEY`;
результат кешируется в базе, так что повторный клик денег не стоит.

Под каждым разбором видно, сколько он стоил и сколько ушло на разборы
всего; накопленный итог лежит в `/stats`.

## Что нужно получить

1. **Токен бота** — у [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. **Open Cloud API-ключ** — [create.roblox.com/dashboard/credentials](https://create.roblox.com/dashboard/credentials),
   кнопка *Create API Key*. Скоупы:
   - `creator-store-save:write` — класть в закладки
   - `creator-store-save:read` — читать закладки
   - `creator-store-product:read` — поднять лимиты поиска

   IP-ограничение: `0.0.0.0/0` (или конкретный IP сервера).
   **Закладки лягут на тот аккаунт, под которым создан ключ.**
3. **Свой chat id** — оставь `TELEGRAM_CHAT_ID` пустым, запусти бота, напиши ему
   что угодно: он ответит своим chat id. Впиши и перезапусти — после этого бот
   отвечает только тебе.

## Локальный запуск

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env      # заполни TELEGRAM_BOT_TOKEN и ROBLOX_API_KEY
.venv/bin/python -m robloxbox
```

Нужен Python 3.11+.

Проверить, что ключ рабочий, до запуска бота (только stdlib, любой python3):

```bash
python3 scripts/probe.py --key ТВОЙ_КЛЮЧ --save-test 8309341353
```

Скрипт скажет, принят ли ключ, и положит указанный ассет в закладки —
дальше открываешь Studio → Toolbox → Saved и убеждаешься глазами.

## Railway

1. Залить репозиторий, создать сервис из этого Dockerfile.
2. **Volume** примонтировать в `/data` — иначе очередь и статистика теряются
   при каждом передеплое.
3. Переменные: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ROBLOX_API_KEY`,
   `DATA_DIR=/data`, дальше по вкусу (см. `.env.example`).
4. Публичный домен **не нужен** — бот работает через long polling.
   В настройках сервиса выключи App Sleeping / serverless, иначе воркер уснёт
   и перестанет собирать новинки.

## Как устроено

| Файл | Что делает |
|---|---|
| `robloxbox/roblox.py` | клиент toolbox-service: поиск, закладки, превьюшки |
| `robloxbox/poller.py` | фоновый сбор — крутит срезы индекса и копит очередь |
| `robloxbox/db.py` | SQLite: очередь, статусы, настройки |
| `robloxbox/bot.py` | команды и кнопки телеграма |
| `robloxbox/constants.py` | значения enum'ов API, снятые эмпирически |
| `robloxbox/analysis.py` | разбор ассета моделью Claude |
| `scripts/probe.py` | диагностика API и проверка ключа |

### Что видит модель при разборе, а чего не видит

**Исходников скриптов достать нельзя.** `assetdelivery.roblox.com` отвечает
`401` и с Open Cloud API-ключом, и без него: содержимое `.rbxm` открывается
только под сессией аккаунта, то есть по cookie. Поэтому разбор построен на
публичных данных — название, описание, автор, рейтинг, цена, даты и техсводка
(число скриптов, полигонов, мешей, аудио).

Промпт прямо запрещает модели делать вид, что она читала код, и объявлять
что-либо вирусом: она говорит о числе скриптов как о поводе проверить вручную.
Описание передаётся отгороженным блоком с пометкой, что это данные, а не
указания — в описаниях ассетов встречается что угодно.

Ссылки модель открывает серверным инструментом `web_fetch`, ограниченным
доменами роблокса. Он ходит только по URL, которые уже есть в переписке, то
есть ровно по тем, что нашлись в описании.

### Как считаются деньги

Цена берётся из `response.usage` по тарифам Claude Opus 5: $5 за миллион
входных токенов, $25 за миллион выходных, чтение кеша $0.50, запись $6.25.
Сам `web_fetch` отдельно **не тарифицируется** — платится только за токены
скачанной страницы, и они приходят обычным `input_tokens`. Поэтому разбор со
ссылками выходит заметно дороже пустого: средняя веб-страница это примерно
2500 токенов, большая документация — все 25000.

Если модель ходила по ссылкам, ответ приходит через `pause_turn` в несколько
приёмов, и каждый оплачивается отдельно — `usage` складывается по всем.
Токены сорвавшегося разбора тоже попадают в счётчик денег (они оплачены), но
не в счётчик разборов.

Две независимые записи: `items.analysis_cost` — что стоил конкретный ассет,
и пожизненные счётчики в `settings`. Второе нужно потому, что строку могут
вычистить из очереди, а потраченные деньги от этого никуда не денутся.

### Про «новинки» — важное

**У Roblox нет ленты «самое новое».** Проверено на живом API:

- на любой запрос приходит максимум **1000 результатов**;
- сортировка работает *внутри* этой урезанной выборки, поэтому
  `CreateTime/Descending` честно отдаёт ассеты **2021 года**, а не свежие;
- `Trending` — единственная сортировка, стабильно достающая свежак
  (самому новому обычно 10–17 дней), но она не поддерживается для
  `Plugin`, `Video` и `FontFamily` — там ручка молча отдаёт пустоту.

Поэтому свежесть добывается двумя приёмами:

1. **Поллер перебирает срезы индекса** — категория × сортировка × поисковый
   запрос × `categoryPath` × глубина страниц. Каждый срез вскрывает свою
   тысячу результатов, вместе они дают тысячи уникальных ассетов за цикл.
   Всё невиданное копится в SQLite, дубли отсекаются по первичному ключу.
2. **Порядок выдачи наводится у себя**: `/next` отдаёт очередь
   отсортированной по `createTime` по убыванию. Ты всегда видишь самое
   свежее из добытого первым.

На практике из ~2000 накопленных ассетов моложе месяца оказываются
единицы-десятки, а моложе трёх месяцев — пара сотен. Поэтому `/fresh 30`
быстро опустошает очередь; `/fresh 90` или выключенный фильтр практичнее.

### Чего здесь нет

- **Комментариев к ассету.** Ручка `toolbox-service/v1/comments` существует, но
  отвечает `401` даже с Open Cloud API-ключом — ей нужна пользовательская
  сессия, то есть cookie `.ROBLOSECURITY`. Публичной альтернативы нет: страница
  магазина отдаёт пустой SPA-каркас без комментариев в HTML. Вместо них в
  карточке техсводка из `toolbox-service/v2/assets/{id}` — она бесплатна,
  не требует авторизации и на практике говорит о модели больше.
- **Лайков.** Голосование (`voting.roblox.com`) официального API не имеет и
  требует cookie `.ROBLOSECURITY` — сознательно не делаем.
- **Добавления в инвентарь.** Старый приём «купить бесплатную модель за 0
  робаксов» сломан: `economy.roblox.com` теперь отдаёт `IsForSale: false` и
  `ProductId: 0` для ассетов Creator Store. Закладки закрывают ту же задачу
  и работают через официальный API.
